Everyday help · You stay in charge

A personal AI assistant that runs on your computer.

Chat with Compa in your browser, using the models you choose. It can work with files, run commands, search the web and answer in your chat apps. Developers can embed its Go runtime.

~/.compa

Install

Windows (PowerShell)

irm https://github.com/xibodev/compa/releases/latest/download/install.ps1 | iex

macOS and Linux

curl -fsSL https://github.com/xibodev/compa/releases/latest/download/install.sh | sh

Compa starts and opens http://localhost:18800 in your browser (or open it yourself). Set a password, then on Models press Try free providers or connect a provider, and start chatting. It runs on Windows 10 or later, macOS 12 or later and Linux.

Options, updates and uninstalling: the install guide.

What it does

  • Chat that can act

    Compa can read, write and edit files in its workspace, run shell commands, search the web, read pages and schedule jobs. Replies can show each tool it called.

  • The models you choose

    Connect OpenAI, Anthropic, Google Gemini, OpenRouter, Groq, Mistral AI and others with an API key, use an Ollama or LocalAI server on your computer or network, or add any OpenAI- or Anthropic-compatible endpoint. Try free providers tests keyless ones for you. A route tries its models in order until one answers.

  • Voice

    Dictate messages and hear replies with the speech models of your providers, push-to-talk or hands-free.

  • Your chat apps

    Talk to Compa from Telegram, Discord, Slack, WhatsApp, Matrix and more. Chat in the browser works without any of them.

  • Skills and modules

    Add skills from the skill hub, or install modules: separate programs that add capabilities. A module capability that needs approval runs only when you approve it.

  • An embeddable Go runtime

    compa-kernel works on its own in a terminal, and pkg/agent runs the same agent loop inside your own Go program.

The web UI is in English, Čeština, Português (Brasil), 简体中文 and বাংলা.

Your data

  • Compa keeps its settings, chats and keys in ~/.compa on your computer.
  • Your messages go to the model providers you choose. Free providers are third-party services, and web search, chat apps and the skill hub reach their own services when you use them.
  • A password protects the web UI, which listens only on this computer unless you turn on LAN access.
  • Tools run as your user account. File tools stay inside the workspace by default: a guard, not a sandbox.
